# ConvertSite plugin for Claude

Build, edit and publish ConvertSite websites and embeds from Claude Code and Cowork.

## What's included

- **ConvertSite MCP server** (`https://convertsite.com/mcp`) — sign in with your ConvertSite account via OAuth on first use.
- **Skills**
  - `convertsite-design-director` — builds or edits sites and standalone embeds (calculators, quote tools, forms, configurators) with conversion-focused design rules.
  - `convertsite-reference-recreator` — recreates an explicitly supplied URL or screenshot in ConvertSite.
  - `convertsite-copy-flow` — transfers your own existing website or brand into ConvertSite, e.g. to run landing pages on a subdomain in your current look.
- **Shortcuts** (manual only)
  - `/cs-site <brief>` — start a new website build
  - `/cs-embed <brief>` — start a new embed
  - `/cs-kopie <url or screenshot>` — recreate a reference

## Requirements

A ConvertSite account. Building, editing and previewing work on any plan; publishing requires a paid plan or an active trial. Nothing is published unless you explicitly ask for it.
